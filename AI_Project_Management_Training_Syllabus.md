# AI Project Management with Claude – Training Package Syllabus

October 2026

## Package overview

This package takes 9 weeks at roughly 5–6 hours per week: about 43 hours of coursework plus 8–10 hours of hands-on practice. The goal is to turn Claude into an active working partner for day-to-day technical project management and technical sales, and to build the skills needed to manage AI projects.

- **Profile:** Mechanical engineer; experience in technical sales and technical project management; Claude 101 and Claude Code 101 completed.
- **Platforms:** Anthropic Academy (anthropic.skilljar.com), PMI (pmi.org), Anthropic GitHub (github.com/anthropics/courses), Coursera (audit mode).
- **Logic:** Conceptual foundations first, then prompting skills, then automation with Claude, AI project management, and finally technical depth. Every module ends with a hands-on task drawn from your own work.

## Module details

### Module 1 – Foundations (Week 1, ~6 h)

Goal: Learn the shared language of working with AI, and its limits.

- **AI Fluency: Framework & Foundations:** A framework for collaborating with AI effectively, efficiently, ethically and safely.
- **Generative AI Overview for Project Managers:** Using generative AI for planning, resource allocation, risk registers and cost estimation; 5 PDUs.
- **AI Capabilities and Limitations:** What AI does reliably and where it fails; the basis for not over-promising to customers.

- [ ] Practice: Classify 5 work items from your last project as "AI can do it / AI can support it / AI can't do it".

### Module 2 – Prompting skills (Week 2, ~6 h)

Goal: Get consistent, structured output from Claude.

- **Talking to AI (PMI):** Writing prompts for reporting, planning, risk analysis and stakeholder communication.
- **Anthropic interactive prompt tutorial:** Role prompting, few-shot examples, XML tags, step-by-step reasoning, reducing hallucinations; with exercises.

- [ ] Practice: Write a reusable prompt template that has Claude analyze a technical specification.

### Module 3 – Automation with Claude (Weeks 3–4, ~6.5 h)

Goal: Hand repetitive work over to Claude.

- **Introduction to Claude Cowork:** An agent that works on your files; preparing reports, summaries and proposal packages.
- **Introduction to Agent Skills:** Define company formats (proposals, risk registers, close-out reports) once and have them applied every time.
- **Claude Code in Action:** Processing Excel data, engineering calculation scripts, report automation.
- **Introduction to Subagents:** Splitting work across specialized sub-agents; keeping context clean.

- [ ] Practice: Create a skill for your proposal or weekly project report format.

### Module 4 – AI project management (Weeks 5–7, ~19 h)

Goal: Manage AI projects from problem to delivery.

- **AI Fluency for Builders:** End-to-end ownership, from defining the problem to delivering the solution.
- **Practical Application of GenAI for PMs (PMI):** Real use cases, tools and workflow automation.
- **Data Landscape of GenAI for PMs (PMI):** Data risks, security threats, data governance. Free for PMI members only.
- **AI for Everyone (Coursera):** Selecting, scoping and positioning AI projects within an organization.

- [ ] Practice: Prepare a one-page AI project proposal for your company (scope, data, risks, success criteria).

### Module 5 – Technical depth (Week 8, ~6 h)

Goal: Speak the same language as developers and be able to build simple tools.

- **Claude Platform 101:** Fundamentals of building tools on Claude via the API; basic Python knowledge helps.
- **Introduction to Model Context Protocol:** How Claude connects to systems such as CRM, ERP and PLM. Python is a prerequisite; if the coding part is hard, the conceptual lessons are enough.

- [ ] Practice: Describe in half a page how a system you use at work (CRM, ERP) could be connected to Claude.

## Capstone project and optional courses

### Capstone project (Week 9, 6–8 h)

Automate a real workflow end to end with Claude. Suggested topic: the weekly project status report or proposal pre-assessment.

1. Write down the current process and the time it takes.
2. Combine the prompt template from Module 2 with the skill from Module 3.
3. Run the work on real files with Cowork.
4. Test the output on 3 real examples and measure quality and time saved.
5. Summarize the result on one page to present to your manager or team.
