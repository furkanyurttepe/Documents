# AI Project Management with Claude – Training Package Syllabus

October 2026

## Package overview

After a preparation week (Week 0), this package takes 9 weeks at roughly 5–6 hours per week: about 48 hours of coursework plus 8–10 hours of hands-on practice. The goal is to turn Claude into an active working partner for day-to-day technical project management and technical sales, and to build the skills needed to manage AI projects.

- **Target audience:** Technical project managers, technical sales professionals and professionals with an engineering background; no software knowledge required.
- **Platforms:** Anthropic Academy (anthropic.skilljar.com), PMI (pmi.org), Anthropic GitHub (github.com/anthropics/courses), Coursera (audit mode), Claude Code for PMs (ccforpms.com).
- **Logic:** Tool and account setup first, then conceptual foundations, prompting skills, automation with Claude, AI project management, and finally technical depth. Every module ends with a hands-on task drawn from your own work.

## Module details

### Module 0 – Preparation (Week 0, ~4–5 h)

Goal: Get tools, accounts and basic usage skills ready before starting the package.

- **Claude 101:** Using Claude for everyday work tasks, core features and further resources.
- **Claude Code 101:** Using Claude Code effectively in your daily workflow.
- **Claude Code for PMs – 0.1 Installation:** Installing Claude Desktop and Claude Code, so you are ready for the Claude Code for PMs lessons in Week 4.
- **Introduction to GitHub (GitHub Skills):** Core concepts such as repos, commits and pushes; for storing your files on GitHub and working in a repo with Claude Code.

Account and tool checklist:

- [ ] Claude Pro or Max subscription active (required for Claude Code and Claude Code for PMs)
- [ ] Claude Desktop installed, Claude Code running
- [ ] Anthropic Academy (Skilljar) account created
- [ ] Free PMI account created
- [ ] Coursera account created
- [ ] SSH key added to your GitHub account
- [ ] Practice: Create and clone a GitHub repo, then commit and push a file with Claude Code.

### Module 1 – Foundations (Week 1, ~6 h)

Goal: Learn the shared language of working with AI, and its limits.

- **AI Fluency: Framework & Foundations:** A framework for collaborating with AI effectively, efficiently, ethically and safely.
- **Generative AI Overview for Project Managers:** Using generative AI for planning, resource allocation, risk registers and cost estimation; 5 PDUs.
- **AI Capabilities and Limitations:** What AI does reliably and where it fails; the basis for not over-promising to customers.

- [ ] Practice: Classify 5 work items from your last project as "AI can do it / AI can support it / AI can't do it".

### Module 2 – Prompting skills (Week 2, ~6 h)

Goal: Get consistent, structured output from Claude.

- **Talking to AI (PMI):** Writing prompts for reporting, planning, risk analysis and stakeholder communication.
- **Anthropic interactive prompt tutorial:** Role prompting, few-shot examples, XML tags, step-by-step reasoning, reducing hallucinations; with exercises.

- [ ] Practice: Write a reusable prompt template that has Claude analyze a technical specification.

### Module 3 – Automation with Claude (Weeks 3–4, ~10 h)

Goal: Hand repetitive work over to Claude.

- **Introduction to Claude Cowork:** An agent that works on your files; preparing reports, summaries and proposal packages.
- **Complete Guide to Cowork (Claude Code for PMs):** A PM-focused, hands-on companion to the Cowork course.
- **Introduction to Agent Skills:** Define company formats (proposals, risk registers, close-out reports) once and have them applied every time.
- **Claude Code for PMs – Modules 0–1:** Using Claude Code inside Claude Desktop without a terminal; file operations, screenshot analysis, parallel agents, custom sub-agents and project memory via CLAUDE.md. A PM-focused, hands-on introduction.
- **Claude Code for PMs – 2.2 Analyze Data:** Analyzing Excel and CSV data with Claude Code; directly applicable to reporting work.
- **Claude Code in Action:** Anthropic's official course, reinforcing the same topics in more depth with a certificate; Excel data processing, calculation scripts, report automation.
- **Introduction to Subagents:** Splitting work across specialized sub-agents and keeping context clean; deepens the custom sub-agents from Module 1.5 with the official source.

- [ ] Practice: Create a skill for your proposal or weekly project report format.

### Module 4 – AI project management (Weeks 5–7, ~19 h)

Goal: Manage AI projects from problem to delivery.

- **AI Fluency for Builders:** End-to-end ownership, from defining the problem to delivering the solution.
- **Practical Application of GenAI for PMs (PMI):** Real use cases, tools and workflow automation.
- **Data Landscape of GenAI for PMs (PMI):** Data risks, security threats, data governance. Free for PMI members only.
- **AI for Everyone (Coursera):** Selecting, scoping and positioning AI projects within an organization.

- [ ] Practice: Prepare a one-page AI project proposal for your company (scope, data, risks, success criteria).

### Module 5 – Technical depth (Week 8, ~6 h)

Goal: Speak the same language as developers and be able to build simple tools.

- **Claude Platform 101:** Fundamentals of building tools on Claude via the API; basic Python knowledge helps.
- **Introduction to Model Context Protocol:** How Claude connects to systems such as CRM, ERP and PLM. Python is a prerequisite; if the coding part is hard, the conceptual lessons are enough.

- [ ] Practice: Describe in half a page how a system you use at work (CRM, ERP) could be connected to Claude.

## Capstone project and optional courses

### Capstone project (Week 9, 6–8 h)

Automate a real workflow end to end with Claude. Suggested topic: the weekly project status report or proposal pre-assessment.

1. Write down the current process and the time it takes.
2. Combine the prompt template from Module 2 with the skill from Module 3.
3. Run the work on real files with Cowork.
4. Test the output on 3 real examples and measure quality and time saved.
5. Summarize the result on one page to present to your manager or team.

## Notes and sources

- **Durations:** Durations for the PMI, Coursera, Google, GitHub Skills and Claude Code for PMs (Modules 0–1, Installation) courses, and the Agent Skills video length (~30 min), come from the course pages; other durations marked (e) are estimates and exclude practice time.
- **Cost:** All courses are currently free; Data Landscape is free for PMI members only, and Coursera courses are free in audit mode (certificate is paid). Claude Code for PMs is free but requires a Claude Pro or Max subscription. Check current status before enrolling.
- **GitHub tutorial:** Running the exercises in code requires an Anthropic API key (small usage cost). Free alternative: read the content and do the exercises directly in a Claude chat.
- **Order:** This order follows the learning flow; it is not identical to the priority ranking.
